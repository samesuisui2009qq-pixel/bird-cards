# 鸟类预习 App —— 部署与使用说明

一个网页版鸟类闪卡工具：**自动读取 GitHub 仓库里的卡片组**，刷闪卡、多组合并刷、收藏到题库。手机和电脑浏览器都能用。

## 一、文件说明

```
bird-cards/
├── index.html          ← 网页 App（这是主体）
└── content/            ← 卡片组目录（网页会自动列出这里的 .json）
    ├── birds.json                     ← 示例/测试组
    ├── 海南推鸟旅行.json               ← 区域分布鸟类（58 张）
    ├── 柳莺辨识：黄胸、黄腰.json        ← 辨识鸟类
    └── 海南鸟单：推鸟旅行.json          ← 区域分布鸟类
```

## 二、部署到 GitHub Pages（免费，一次配置，永久使用）

### 第 1 步：新建仓库

1. 打开 https://github.com ，登录你的账号
2. 点右上角 **「+」→ New repository**
3. 仓库名填 `bird-cards`，选 **Public（公开）**，点 **Create repository**

> ⚠️ 必须选 **Public（公开）**。网页靠 GitHub API 读取 `content/` 目录，私有仓库的 API 需要令牌，访客读不到。

### 第 2 步：上传文件

在仓库页里：

1. 点 **「uploading an existing file」**（或 Add file → Upload files）
2. 把本地的 **`index.html`** 和 **`content` 文件夹**（整个文件夹）一起拖进去
3. 点 **Commit changes** 提交

> 也可以分次上传：先拖 `index.html`，再用 Add file → Create new file 创建 `content/xxx.json`。

### 第 3 步：开启 Pages

1. 仓库页点 **Settings** → 左侧 **Pages**
2. **Source** 选 **Deploy from a branch**
3. **Branch** 选 **main**，文件夹选 **/ (root)**，点 **Save**
4. 等约 1 分钟，页面顶部会显示网址：
   ```
   https://你的用户名.github.io/bird-cards/
   ```

## 三、开始使用

1. 用手机或电脑浏览器打开网页地址
2. 页面会**自动列出**仓库 `content/` 目录里所有的卡片组
3. 点某组的 **「刷闪卡」** 开始；没信号的山区可以先刷一次，之后会自动缓存到本机

### 搜索卡片组

在「卡片组」区域上方的**搜索框**输入关键词，列表即时过滤：

- 输入地名，如 `海南` → 只显示海南相关的组
- 输入组名片段，如 `推鸟旅行`、`柳莺` → 精确命中
- 输入类型，如 `辨识`、`区域分布` → 按类别找

搜索范围包含**组名、文件名和类型**三处，匹配到就显示。

### 多组合并刷闪卡

1. 勾选想一起刷的多个分组（每组前面有个方框，可勾选 **2 个以上**）
2. 底部出现操作条，显示「已选 N 组」
3. 点 **「合并刷闪卡」**——各组卡片会**交错混合**（不会连着刷完一整组），可勾选「乱序」再彻底打乱

### 辨识点

「辨识鸟类」组可以带**辨识点图**（标注过的对比图）。刷这组闪卡时，**「⭐ 收藏」右边**会出现 **「🔍 辨识点」** 按钮。

- 只在该组有 `marks` 时才显示
- 点开后**就在闪卡这一页展开**（不是弹窗），图竖排可以上下滚动看
- **点任意一张图进入放大**：双击放大 / 双指缩放 / 拖动查看 / 滚轮缩放，顶部有 ‹ › 可在多张之间切换
- 每张图左上角标注「第几张 / 共几张 · 像素尺寸」
- 合并多组刷时，会把各组的辨识点图汇总显示，并标注来自哪一组
- 首次点开会顺带把这组缓存到本机，之后秒开

### 辨识点图的清晰度要求

放大后要看得清，取决于**源图的分辨率**：

- 辨识点图按**全分辨率、无损**保存（不缩放、不压缩画质），浏览器里放大到原始像素都是清晰的
- 角标会显示实际像素，例如 `1 / 1 · 2400×1800`
- **建议源图宽度 ≥ 1600px**。低于这个尺寸，放大到极限后仍会有插值模糊
- 多张图可以**合并成一张**再放进来（更省事，也避免切页）

### 在本机删掉不想看的组

点组右边的 **「删除」**，这组就从**你这台设备**的列表里消失（GitHub 上的文件不受影响）。下方「已移除的组」里可以随时 **恢复**。

## 四、以后怎么更新内容（最省事的做法）

### 方式 A：改已有的一组 —— 替换文件

1. 在网页上找到这一组，点组名下面的 **「↗ 替换」** → 跳到 GitHub 上这个文件
2. 在 GitHub 文件页点铅笔图标（✏️），把新文件拖进去替换
3. 填个提交说明，**Commit changes**
4. 回到网页点 **「刷新列表」**，新内容立刻生效

> 不用改文件名，也不用改 `name` 字段，网页上显示的名字保持不变。

### 方式 B：加一个新组 —— 上传文件

1. 点首页顶部的 **「📤 上传新卡片组」** → 直接跳到 GitHub 的 `content/` 上传页
2. 把新的 JSON 拖进去，**Commit changes**
3. 回到网页点 **「刷新列表」**

### 方式 C：让 AI 帮你生成文件（最省力，推荐）

1. 在 Word 里排版好（图片 + 名字，见下）
2. 把 Word 放到桌面，告诉 AI 一句话：「把这个 docx 转成卡片组」
3. AI 生成好 `content/xxx.json`，你只管拖去 GitHub 上传

### 不用每次都传 index.html

- **只改内容** → 只传 `content/` 里的 JSON
- **网页功能有升级** → 才需要传 `index.html`

### 出问题时先看「📋 同步诊断」

展开首页的 **「📋 同步诊断」**，能看到每个文件的实际读取情况：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| ⚠ 内部名与文件名不一致 | 文件里的 `name` 和文件名不同 | 建议改成一致，避免混淆 |
| ⚠ 缺 type | 没写 `type` 字段 | 补上 `辨识鸟类` 或 `区域分布鸟类` |
| ⚠ 还没读到 name | 文件读不到 | 检查 JSON 格式，或点「刷新列表」 |

## 五、内容文件的格式（JSON）

```json
{
  "name": "柳莺辨识：黄胸、黄腰",
  "type": "辨识鸟类",
  "marks": ["data:image/webp;base64,……"],
  "cards": [
    { "name": "黄胸柳莺", "image": "data:image/webp;base64,……" },
    { "name": "黄腰柳莺", "image": "data:image/webp;base64,……" }
  ]
}
```

- `name`：这一组的显示名（**必须和文件名一致**，否则会出现「叫 A 显示 B」）
- `type`：卡片组类型，两个值之一
  - `辨识鸟类` —— 相似鸟种放一起练区分（如「柳莺辨识：黄胸、黄腰」）
  - `区域分布鸟类` —— 某个地方的鸟单（如「海南鸟单：推鸟旅行」）
- `marks`（可选）：**辨识点图**，数组。写了这一项，刷这组闪卡时「⭐ 收藏」旁边会多出一个 **【🔍 辨识点】** 按钮，点开就是这些图
- `cards`：鸟图 + 鸟名
- `image`：图片内嵌为 base64（**WebP 格式体积最小**，JPEG/PNG 也能用）

> `marks` 必须放在 `cards` **前面**。网页只读文件开头 2KB 就能判断有没有辨识点图，不用下载整份文件。

### 命名规则（重要）

1. **文件名 = `name` = 组名**，三者完全一致
2. **组名建议以地名开头**，这样搜地名就能直接找到：
   - 区域分布鸟类 → `海南鸟单：推鸟旅行.json`
   - 辨识鸟类 → `柳莺辨识：黄胸、黄腰.json`
3. 文件名不能含 `:` `/` `\` `?` `*` `<` `>` `|` 这些字符（Windows 限制），请用全角 `：` 或 `-`
4. 同一地方可以有多组，用冒号区分用途：`海南鸟单：推鸟旅行`、`海南鸟单：红树林`

> 你以后把鸟图+名字发给我（Word 文档即可），我帮你生成合规的内容文件，你只需拖进 `content/` 提交即可。

### Word 文档怎么写

在 Word 里按这个顺序排版，我就能自动转换：

```
[图片]
黄胸柳莺
[图片]
黄腰柳莺
[图片]
*辨识点*
```

- 每张图后面紧跟它的名称
- 辨识点图后面跟 `*辨识点*`（带星号或不带都行）

## 五、常见问题

**Q：列表里没出现新文件？**
点「刷新列表」；仍不出现就检查：① 文件确实在 `content/` 目录下（不是仓库根目录）；② 扩展名是 `.json`；③ 仓库是 Public。

**Q：提示「GitHub API 403（频率限制）」？**
未登录的 GitHub API 每个 IP 每小时限 60 次。稍等几分钟再点「刷新列表」即可；网页已经缓存了上次列表，读取失败时会自动显示缓存内容。

**Q：图片加载慢？**
图片是 base64 内嵌的，文件大（58 张约 3.9MB）。**刷过一次之后会自动缓存到本机**，之后刷就秒开了。

**Q：收藏的题库能跨设备同步吗？**
不能。「我的题库」是**本机存储**（浏览器 IndexedDB），换设备或清缓存就没了。共享的只有 `content/` 目录里的卡片组。
